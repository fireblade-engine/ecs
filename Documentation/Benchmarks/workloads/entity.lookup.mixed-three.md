# `entity.lookup.mixed-three`

[Back to the report](../REPORT.md) · [Glossary](../REPORT.md#glossary). FirebladeECS benchmark comparison.

- Parity (1.4.3, main): adapted: population and lookup count match; payload is a single Int per component and gets return the component; component types are declared with @Component (stored static componentIndex) on value revisions and by plain class conformance on 1.x; the generic CompatBox stays plain on every revision; state is built once and kept across iterations as upstream; sampling is time-based (0.5 s, no warmup) so pass count and world state can differ by revision, as upstream

`median`, `CI low`, `CI high`, `replicates` and `iterations` are defined in the [report](../REPORT.md). `mean` is the median over replicates of each replicate's mean per iteration; it is descriptive (upstream parity), not an inference input. Percentile columns are the median over replicates of each replicate's percentile.
